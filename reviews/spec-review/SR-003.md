# Spec review: DESIGN.md SR-003

_2026-11-21T19:04:57+00:00 · claude-sonnet-5-5 with claude-fable-5-2 advisor (1 calls)_

I checked the advisor's added pairs against the plan text. I found no contradiction, only ambiguities. I merged some of the advisor's pairs into the existing ambiguities and dropped two as too weak.

- **SR-003.2 / SR-003.5 (A1):** With an injected transport and a ledger but no prices file, the reservation can't be priced.
- **SR-003.1 / "Links introduced" / SR-003.9 (A2):** A held row left by a dead process is never released automatically. The ceiling may be raised by hand only while no row is held. The plan doesn't say how a stuck ledger is cleared. The hand edit also sits outside the rule that every read and write goes through `review_run.locked()`.
- **SR-003.3 / SR-003.4 / SR-003.9 / SR-003.5 (A3):** It's unclear whether the bound is a guarantee or an estimate. A = 3 may be lower than what `max_uses` allows across 8 requests. A stale price rate can also push an actual above the reservation.
- **SR-003.8 / SR-003.2 / SR-003.4 (A4):** "Neither changes a finding" is unclear when a refused or stopped scope gets no record.
- **SR-003.4 / SR-003.1 (A5):** Settlement lowers a held row's reservation to the actual, but the plan also says a write "never lower[s] a recorded commitment". It doesn't define "commitment".
- **SR-003.7 / SR-003.2 / SR-003.8 (A6):** Every record `run` writes gets a fresh `review_id`, so a re-run invalidates dispositions. The plan doesn't say what happens when a run is refused or stopped. In that case it may write no record, or a record for only some scopes.
- **SR-003.6 / "What's not taken" / "Transcript-derived data…" (A7):** A disposition's `--evidence` quotes Dorian's session words. The committed `dispositions.json` and review packet are readable. The plan calls this "a ruling quoted by hand" and not "data built from a session file", but doesn't say the publish gate doesn't apply.
- **SR-003.1 / "Test the boundaries before adding item IDs" (A8):** It's unclear whether `budget show`, which prints `spent_usd`, `held_usd` and `remaining_usd`, counts as new "metrics" work. The plan says it is "not a new measurement report".
