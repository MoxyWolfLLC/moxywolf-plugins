# Spec review: DESIGN.md GR-001

_2026-11-21T03:52:19+00:00 · claude-sonnet-5-5 with claude-fable-5-2 advisor (1 calls)_

I found no contradictions in GR-001 or in the constraints it touches. Each tension I tested has a reading under which both requirements hold. I did list eight ambiguities, where the plan's text can't settle whether a requirement is met. I left out the advisor's weaker items, such as the `run_all_tests.py` and recursion-refusal ones, because the plan doesn't state a requirement they break.

1. **GR-001.4: manifest identity.** "Written once" and "may differ only in `width`" don't say how a second run is checked against the first. `width` is inside the manifest, so changing it changes the sha256. Each ledger records only its own manifest hash, so the plan doesn't say what "not the same manifest" is compared against. It also doesn't say whether the two runs share a ledger. They can't, because GR-001.1 allows one fan-out and refuses `init` on an existing id.
2. **GR-001.1 and GR-001.7: monotonic timestamps.** The 90-minute deadline is "counted from `init`" and survives `resume` and a restart. Events carry monotonic timestamps, which don't carry across a restart or reboot. The plan doesn't say which clock the deadline and the remaining time use.
3. **GR-001.7: draft-to-decision time.** The report must compute it "from those events alone". It runs from first dispatch to "the final disposition timestamp", but the plan defines no disposition event. Reconcile belongs to GR-002, which this item excludes.
4. **GR-001.5 and "Not in this item".** The Codex command must come from `peer_review.py`'s builder, "not a copy". The item also bars any change to `peer_review.py`'s behavior. If no standalone builder exists, or it lacks `--sandbox read-only --ephemeral`, the plan doesn't say whether extracting or changing it is allowed.
5. **GR-001.3 and GR-001.5: the Claude lane's timeout.** Only the Codex ceiling (900 seconds) is stated. The ceiling for `claude -p` lanes is undefined.
6. **GR-001.2 and GR-001.1: the council-gate flag.** The plan doesn't say which command takes `--council-gate-ruling`. Code also can't decide whether a reference "names Dorian's recorded ruling". That leaves "satisfied" undecidable.
7. **GR-001.1, GR-001.2 and GR-001.4: width against the call limits.** `width` is unbounded, but the Codex-call limit is 10 and there is one fan-out. The plan doesn't say whether a fan-out wider than the remaining calls is refused whole or admitted in part.
8. **GR-001.1 ($1.00) and GR-001.6.** The dollar counter has no stated cost source. The API-key backup is off, and the tests make no paid call.
