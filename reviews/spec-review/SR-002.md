- **SR-002.4:** The test for whether an entry "names the reviewed item's id" is undecidable when the item is one a constraint cites, such as GA-011. The same criterion says an id a constraint's own text cites "doesn't count". It doesn't say how to tell a requirement naming the id from a constraint merely citing it.
- **SR-002.1 and SR-002.6:** The constraints scope is `## Goal` and `## Constraints and settled decisions` alone, holding nothing from `## Items and acceptance criteria` onward. The plan as given has no `## Items and acceptance criteria` heading before SR-002, which sits as a `###` subsection under the constraints. Where the scope ends can't be decided from the text.
- **A goal delegates item selection, not authority, and The pre-merge gate is GitHub's, sized to the stakes:** "A goal's folder" is called a `CODEOWNERS` path. The gate text says a goal's own `goal-runs/<id>/` isn't owned (GO-011.2), and only `goals/` and `goal-runs/README.md` are. It is unclear which folder is meant.
- **SR-002.3 and The pre-merge gate is GitHub's, sized to the stakes:** The seed asks which paths "a change touching any of those" covers. The gate text no longer contains that phrase, so the seed can't be matched to a requirement.
