I found no contradictions in the plan's text. I found three ambiguities, all in XE-045.

- **XE-045.4:** The criterion doesn't say what an entry reads as when it names a different set of repositories and also a different head in a shared repository. The text allows `absent` or `ran_earlier`.
- **XE-045.4 with XE-045.7:** Criterion 4 reads `ran_earlier` whenever any head moved after the first pre-pass. Criterion 7 treats `ran_earlier` as proof the builder acted on the pre-pass ("the builder changed nothing after a pre-pass"). A moved head doesn't show the builder acted on the questions.
- **XE-045.7 with XE-045.4:** Criterion 7 counts reviews by first repository, "read from the `state.json` files". Criterion 4 has `open` write only one field, `goldfish`. The repository identity sits in the goldfish record, so the count can't be read from `state.json` unless it already holds that identity.
